## Tools on this machine
- Structural code search/refactors: `ast-grep` (sg) instead of regex grep/sed.
- File search in Bash: `rg`, `fd` instead of grep -r / find.
- If a repo has a `justfile`, run checks via `just` (`just --list`).
- GitLab: `glab`; GitHub: `gh`.
- Runtimes via `mise` (mise use / mise.toml), never brew/nvm/asdf for languages.
